## 📌 Project Overview

Traveller is a front-end hotel booking website designed to provide users with a smooth hotel searching and booking experience.

The project allows users to:

- Browse available hotels
- Search hotels by location and name
- Filter hotels using multiple options
- Sort hotels based on price and rating
- View hotel details
- Complete booking flow
- Manage user-related pages


The project is developed using:

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- JSON data handling

## ✨ Features


### 🏨 Hotel Listing

- Dynamic hotel cards
- Hotel images
- Hotel names
- Ratings and reviews
- Pricing information
- Discount badges


### 🔎 Search System

Users can search hotels using:

- Hotel name
- Location


### 🎯 Filtering System

Multiple filters are available:

- Price range
- Rating
- Popular filters
- Activities
- Hotel category


### ↕️ Sorting System

Hotels can be sorted by:

- Recommended
- Price low to high
- Price high to low
- Rating


### 🛒 Booking Flow

Includes:

- Hotel details page
- Checkout page
- Booking confirmation page


### 👤 User Pages

Includes:

- Registration
- Login
- Password recovery
- User trip management

## ⚙️ How To Run The Project Locally


### 1. Clone the repository

```bash
git clone https://github.com/asamiiAlam/Traveller-Project.git
```


### 2. Open the project

Open the folder in Visual Studio Code.


### 3. Run with Live Server

Install the VS Code extension:

```
Live Server
```

Then:

```
Right click index.html
→ Open with Live Server
```
